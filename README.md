# SmartFloor

스터디카페 도면 이미지를 올리면 **좌석 도면처럼 단순화한 벽 도면**(같은 두께·직각, 건축 디테일 없음)을 만들고, 웹에서 편집·내보내기(PNG/JSON/Figma)까지 하는 서비스. 벽은 흰 바탕에 `#D9D9D9` 한 색으로만 칠한다 (테두리·격자 없음).

- 사이트: https://kwackgwon.github.io/smartfloor/
- 기본 생성은 **AI 없이** 이미지 분석만으로 한다 → 무료, 한도 없음, 키 필요 없음
- **AI로 다듬기**(선택, 접혀 있음): 보통은 필요 없다. 빠진 벽이 있을 때 Gemini 또는 OpenRouter 무료 비전 모델이 한 번 더 본다 (느림)

> 현재는 벽 도면만 만든다. 좌석 배치·좌석 상태 관리는 벽 도면이 안정화된 뒤 다시 추가할 예정.

## 사용법

1. **① 도면 이미지**를 올린다 (PNG · JPG · WEBP, 10MB 이하)
2. **② 건물 가로 길이(m)**를 넣는다 (선택). 실제 크기(cm)를 맞추는 데 쓴다
3. **도면 생성** → 1~2초 안에 벽 도면이 나온다 (AI 없이)
4. (선택) **AI로 다듬기**: ⚙ AI 설정에 키를 넣고 누른다
   - Gemini 키: https://aistudio.google.com/apikey
   - OpenRouter 무료 키: https://openrouter.ai/keys (`:free` 비전 모델을 자동으로 고른다)
   - 둘 다 있으면 Gemini 를 먼저 쓰고, 한도에 걸리면 OpenRouter 로 넘어간다
5. 편집: **✏ 벽 그리기**를 켜고 도면 위를 드래그하면 벽 추가 (수평/수직 자동 정렬, Shift = 사선, 10cm 격자). **↶ 되돌리기**(Ctrl+Z)로 방금 그린 벽·다시 생성·AI 다듬기 전 도면으로 돌아간다 → **저장**
   - 벽 그리기가 꺼져 있으면(기본) 휴대폰에서 도면 위를 쓸어도 화면만 스크롤된다
6. **PNG** 로 도면 이미지, **JSON** 으로 Figma 플러그인용 데이터 저장

키는 사용하는 브라우저의 `localStorage` 에만 저장되고 각 AI 호출에만 쓰인다. 서버는 없다 (GitHub Pages 정적 사이트).

## 동작 방식

**이미지 분석 (`trace.js`, AI 없이)**
0. **이미지 고르게 맞추기**: 긴 변이 1600px 보다 작으면 키운다. 배경이 어두우면(반전 도면) 뒤집고, 스캔 잡음(이웃 픽셀 차이의 중앙값 > 2)이 있으면 5x5 중앙값 필터로 지우고, 회색 배경이면 배경을 흰색으로 펴서 대비를 맞춘다. 배경이 연회색 벽보다 어두우면(배경보다 밝은 봉우리가 따로 있으면) '배경과 다른 정도'를 잉크로 바꾼다. 유채색이 40% 넘거나 배경색이 30% 도 안 되는 이미지(사진 등), 가장 큰 벽 덩어리가 벽 픽셀의 10% 도 안 되는 이미지(글자만 있는 이미지)는 도면이 아니라고 안내한다
1. **벽 색 고르기**: 무채색 밝기 분포의 봉우리마다 그 밝기의 두꺼운 픽셀을 모아, 가장 넓게 이어진 덩어리를 만드는 색을 벽 색으로 고른다 (검게 칠한 CAD 도면, 연회색 디자인 도면 모두)
2. **벽 픽셀**: 벽 색 픽셀 중 5px 보다 얇은 것(치수선·글자·집기 선)을 지운다. 빗금(해치)이나 2~3줄로 그린 벽은 촘촘한 무늬를 메운 뒤, 길고 곧으며 긴 두 변이 곧은 선이고 다른 벽에 이어진 막대만 벽으로 더한다 (두께는 한 칸씩 재서 붙어 있는 곡선 가구는 빼고 곧은 부분만, 같은 줄에서 문 폭 이하 틈 너머로 이어지는 건물 안 벽도 포함). 아주 얇은 빗금벽은 바로 옆 가구와 뭉치기 전에 평행한 두 긴 선 사이의 빗금(잉크 15~75%)으로 따로 찾는다. 두 선 사이 속에 빗금·점무늬 잉크가 8% 도 없으면 속 빈 두 줄 선(책상·부스 칸막이 외곽, 계단 난간)이라 벽이 아니다. 건물 안에서 이런 칸막이가 3개 이상 붙은 긴 선은 책상 줄 테두리라 뺀다
3. **건물 영역**: 가장 큰 벽 덩어리에서 시작해 가까운 덩어리를 붙인다 (표제란·좌석표·로고·글자 조각 제외)
4. **창문 메우기**: 외벽의 칠해진 벽 사이가 얇은 선으로만 이어진 틈을 메운다 (건물 바깥과 맞닿고 긴 변이 벽에 붙지 않은 것만)
5. **외벽 닫기**: 건물 윤곽을 따라 고른 두께의 띠로 외벽을 깐다 (입구·문 틈까지). 외벽 안쪽으로 얕게 튀어나온 것(기둥 돌출·문틀)은 지우고, 깊이 들어가는 내부 벽은 뿌리만 남겨 잇는다
6. **얇은 벽 찾기** (연한 색으로 칠한 디자인 도면만, CAD 도면의 얇은 한 줄 선은 대부분 가구라서 쓰지 않음): 칠해진 벽을 뺀 벽 색 선 중 곧은 가로·세로 선(긴 변의 4% 이상)이 건물 안에 있고 한쪽 끝이 벽에 닿으면 칸막이로 되살린다. 짧은 선이 촘촘히 반복되는 무리(계단)는 빼고, 두 줄로 그린 벽은 한 벽으로 메운다
7. **좌석 도면처럼 단순화**: 건물 윤곽을 크게 단순화(직선·직각)해 고른 두께의 외벽 띠로 다시 그리고, 내부 벽은 가로·세로 막대로 나눠 모두 같은 두께(중앙값)로 그린다. 외벽은 내벽의 1.8배 이상 두께로 그린다. 거의 한 줄인 벽은 한 줄로 맞추고, 벽 끝은 만나는 벽의 바깥 면에 맞춘다. 외벽에 붙은 꽉 찬 덩어리는 기둥 크기(외벽 두께의 6배 이하)만 기둥으로 남기고(벽에 붙은 탁자·카운터 제외), 막대로 나뉘지 않는 가는 덩어리(사선 벽)는 모양 그대로 둔다
8. **벽 잇기 (문은 그리지 않음)**: 좌석 도면처럼 문 자리를 비우지 않고 벽을 잇는다. 같은 줄(가로·세로)의 벽이 문 폭(1.3m) 이하 틈으로 떨어져 있으면 하나로 합치고, 다른 벽에 못 미친 벽 끝은 그 벽까지 늘리고, 이미 닿은 끝이라도 바로 너머(두께 2.5배 안)에 수직 벽이 있으면 거기까지 잇는다 (0.4m까지. 1.5m 이상 긴 벽은 늘릴 길에 원래 선이 절반 넘게 있을 때만 1.1m까지 — 빈 통로를 가로지르지 않게). 양 끝이 모두 떠 있는 짧은 막대(좌석 구분선 등)는 지운다
9. **떨어진 덩어리 빼기**: 벽에 붙지 않은 기둥·화분·가구, 벽에 붙었어도 들쭉날쭉한 작은 덩어리는 그리지 않는다
10. **축척**: 입력한 가로 길이 > AI 가 읽은 도면 치수 > 가로 15m 가정

**AI로 다듬기 (`gemini.js`, `openrouter.js`)**
- AI 에게 "자기 생각·추측으로 만들지 말고 이미지에 그려진 것만" 건물 영역·벽 중심선(이미지 기준 0~1000 정규화 좌표)·가로 치수를 받는다 (같은 프롬프트·응답 형식)
- 받은 벽 선분은 실제 선 픽셀에 맞춰 위치·기울기·끝점·두께를 보정하고, 근거 픽셀이 없는 선분은 버린다
- Gemini: 생각 수준 high, 스트리밍. 시간 초과면 low 로, 사용량 폭주면 다른 flash 모델로 다시 시도
- OpenRouter: 무료 비전 모델 목록을 조회해 응답 형식 강제(structured outputs)가 되는 모델부터 최대 3개 시도
- 실패하면 AI 없이 만든 도면은 그대로 두고, 원인·할 일·권장 대기 시간과 **다시 시도** 버튼으로 안내한다

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 (① 도면 이미지 ② 가로 길이 → 도면 생성 / AI로 다듬기 / 도면 보기) |
| `trace.js` | 이미지 분석 (벽 색·벽 픽셀·창문 메우기·외벽 닫기·얇은 벽·좌석 도면식 단순화·AI 벽 선분 보정) |
| `gemini.js` | Gemini 호출 (스트리밍), 프롬프트·응답 형식 (OpenRouter 도 같이 씀) |
| `openrouter.js` | OpenRouter 무료 비전 모델 호출 |
| `app.js` | 화면 동작, 생성·다듬기·재시도, 오류 안내, 벽 그리기, 저장, PNG/JSON 내보내기 |
| `figma-plugin/` | JSON → Frame + 벽 모양·선 Vector(#D9D9D9) |
| `tools/real-run.js` | 개발용: 사이트를 브라우저에서 그대로 돌려 결과·AI 원본 응답을 저장 |
| `tools/bench/` | 개발용 연습·채점: `gen.py` 가 정답 벽 마스크(문 자리도 벽)가 있는 연습 도면을 4가지 스타일로 만들고, `score.js` 가 벽 정확도·찾음을 잰다 |

Figma: `cd figma-plugin && npm i && npm run build` → Figma 데스크톱 *Plugins › Development › Import plugin from manifest* → 플러그인 창에 `smartfloor.json` 내용 붙여넣기 (Node 필요)

## 알려진 한계

- 얇은 벽은 곧은 가로·세로 선만 찾는다 (사선 얇은 벽, 벽에 닿지 않고 떨어져 있는 얇은 벽은 빠진다 → AI로 다듬기 또는 직접 그리기)
- 좌석 옆 칸막이처럼 벽과 같은 색으로 칠한 두꺼운 선(속이 찬 것)은 벽으로 같이 그려진다 (한쪽이 벽에 붙은 짧은 칸막이는 남는다)
- 빗금 벽 도면을 스캔한 이미지는 빗금이 잡음과 함께 지워져 벽이 빠질 수 있다
- 화면에서 벽을 골라 지우는 기능은 없다 (되돌리기·다시 생성으로 고친다)
- 내부 벽은 모두 같은 두께로 그린다 (실제 두께 차이는 표현하지 않는다)
- 문은 그리지 않는다: 외벽·내벽의 문 자리는 모두 벽으로 닫힌다
- 책상 칸막이처럼 벽과 같은 두께로 그린 선은 벽으로 보고, 같은 줄이면 통로(1.3m 이하) 너머로 이어 그릴 수 있다
- 무료 AI 는 분당·하루 사용 한도가 있고, OpenRouter 무료 모델 목록은 자주 바뀐다
- 배포 후 예전 화면이 보이면 Ctrl+F5. 배포할 때 `index.html` 의 `?v=` 숫자를 올린다
- 저장본에 형식 버전(`v`)이 있어, 예전 형식으로 저장된 도면은 불러오지 않는다
