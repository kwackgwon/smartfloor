# GG_PBL_Project — SmartFloor

참고 도면 이미지를 올리면 **벽만 정확하게 옮겨 그린 도면**을 만들고, 웹에서 편집·내보내기(PNG/JSON/Figma)까지 하는 서비스. 벽 색상은 `#D9D9D9`.

> 현재는 벽 도면만 만든다. 좌석 배치·좌석 상태 관리는 벽 도면이 안정화된 뒤 다시 추가할 예정.

## 동작 방식

**설치·서버 없음.** 브라우저가 Gemini API 를 직접 호출한다 (`gemini.js`, 스트리밍 + JSON 스키마 강제).

**참고 도면을 올린 경우 — 옮겨 그리기 (벽만)**
1. **벽 모양은 이미지 픽셀에서 그대로 가져온다**: 진한 무채색·빨간색 픽셀 중 5px 보다 얇은 것(치수선·글자·집기 선)을 지우면 칠해진 벽·기둥·칸막이만 남는다 → 덩어리별 외곽선을 다각형으로 옮긴다
2. **Gemini 는 판단만 한다**: 건물 영역(extent)과 벽 위치를 이미지 기준 0~1000 정규화 좌표로 알려 준다
   - 건물 영역 밖(표제란·좌석표·로고)과 작은 조각(글자)은 버린다
   - 칠해진 벽이 없는 곳의 Gemini 벽 선분(창문 구간, 얇은 칸막이)은 실제 선 픽셀에 맞춰 위치·기울기·두께를 보정해 메운다. 근거 픽셀이 없는 선분은 버린다
3. 도면 치수(mm)로 실제 크기(cm)로 바꾼다. 좌석·문·글자는 넣지 않는다

**참고 도면이 없는 경우 — 설계**: 요청 사항(글)에 맞춰 벽을 cm 좌표로 직접 설계한다.

벽은 `#D9D9D9` (테두리 `#BDBDBD`), 공간 이름 같은 글자는 넣지 않는다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 (API 키·도면 이미지·요청 사항 입력, 툴바, Canvas) |
| `gemini.js` | Gemini 호출(스트리밍), 프롬프트·응답 스키마, 이미지 벽 추출·다각형화, 벽 선분 보정 |
| `app.js` | Canvas 렌더링, 벽 그리기·지우개, 저장(localStorage), PNG/JSON 내보내기 |
| `figma-plugin/` | JSON → Frame + 벽 모양·선 Vector(#D9D9D9) |

## 실행

1. https://aistudio.google.com/apikey 에서 Gemini API 키 발급
2. `index.html` 더블클릭 (Chrome/Edge 권장)
3. **Gemini API 키** 칸에 키 붙여넣기 (이 브라우저에 저장되어 다음부터는 자동 입력). 모델은 키로 쓸 수 있는 최신 Flash 가 자동 선택됨 (단종 모델이면 Google 이 안내하는 모델로 자동 재시도)
4. 참고 도면 이미지를 올리고 (요청 사항은 선택) → **생성 방식** 선택 (빠르게 / 균형 / 정밀하게) → **Gemini로 도면 생성**
   - 진행 상황(분석 중 → 벽 n개 그리는 중 → 다듬는 중)과 경과 시간이 표시된다
5. 편집: **벽 그리기**(수평/수직 자동 정렬, Shift = 사선, 10cm 격자) · **지우개** → **저장**
6. **PNG** 로 도면 이미지 저장, **JSON** 으로 Figma 플러그인용 데이터 저장
7. (선택, Node 필요) Figma: `cd figma-plugin && npm i && npm run build` → Figma 데스크톱 *Plugins › Development › Import plugin from manifest* → 플러그인 창에 `smartfloor.json` 내용 붙여넣기

## 알려진 한계

- 칠해진 벽은 이미지 픽셀에서 가져와 매번 같지만, 얇은 칸막이·창문 구간은 Gemini 판단에 따라 매번 조금 다를 수 있다 → 다시 생성하거나 직접 보정.
- 배포 후 예전 화면이 보이면 Ctrl+F5. 배포할 때 `index.html` 의 `?v=` 숫자를 올린다.
- 저장본에 형식 버전(`v`)이 있어, 예전 형식으로 저장된 도면은 불러오지 않는다.
- API 키는 브라우저 `localStorage` 에 저장되고 Google 에만 전송된다. 키가 들어간 채로 웹에 공개 배포하지 말 것 (공용 PC 에서는 사용 후 키 칸을 비우기).
- 저장소는 브라우저 `localStorage` 라 다른 브라우저/기기와 공유되지 않는다. DB·인증 없음.
- 실행 취소(Undo) 없음.
