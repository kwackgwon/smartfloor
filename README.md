# SmartFloor

스터디카페 도면 이미지를 올리면 **좌석 도면**(단순화한 벽 + 문 + 좌석 번호, 같은 두께·직각, 건축 디테일 없음)을 만들고, 웹에서 편집·내보내기(PNG/JSON/Figma)까지 하는 서비스. 벽은 투명 바탕에 `#D9D9D9` 한 색으로만 칠한다 (테두리·격자 없음, PNG 도 투명 배경).

- 사이트: https://kwackgwon.github.io/smartfloor/
- 이미지 분석만으로 만든다 (AI 사용 안 함) → 무료, 한도 없음, 키 필요 없음, 서버 없음

> 좌석은 원본 도면에 그려진 책상·탁자·좌석 상자에서 자동으로 찾는다. 좌석 상태 관리는 이후 추가 예정.

## 사용법

1. **① 도면 이미지**를 올린다 (PNG · JPG · WEBP, 10MB 이하)
2. **② 건물 가로 길이(m)**를 넣는다 (선택). 실제 크기(cm)를 맞추는 데 쓴다
3. **도면 생성** → 3~5초 안에 벽·문·좌석 도면이 나온다
4. (선택) **🔤 구역 이름**을 켜고 좌석을 누르면 그 구역(방) 좌석 번호의 글자를 한꺼번에 바꾼다 (예: A01~A16 → H01~H16). 도면 이미지에는 구역 이름이 없어서 처음에는 방마다 A, B, C… 로 붙는다
5. 편집: 좌석·문·탁자도 **🧽 벽 지우기**로 지울 수 있다. **✏ 벽 그리기**를 켜고 도면 위를 드래그하면 벽 추가 (수평/수직 자동 정렬, Shift = 사선, 10cm 격자). **🧽 벽 지우기**를 켜고 벽을 누르면 그 벽이 지워진다 (마우스를 올리면 지울 벽이 빨갛게 보임. 휴대폰은 첫 탭에 빨갛게 고르고 같은 벽을 한 번 더 누르면 지움. Esc = 보기 모드). **↶ 되돌리기**(Ctrl+Z)로 방금 그리거나 지운 벽·다시 생성 전 도면으로 돌아간다 → **저장**
   - 벽 그리기가 꺼져 있으면(기본) 휴대폰에서 도면 위를 쓸어도 화면만 스크롤된다
6. **PNG** 로 도면 이미지, **JSON** 으로 Figma 플러그인용 데이터 저장

도면은 사용하는 브라우저의 `localStorage` 에만 저장된다. 서버는 없다 (GitHub Pages 정적 사이트).

## 동작 방식

**이미지 분석 (`trace.js`)**
0. **이미지 고르게 맞추기**: 긴 변이 1600px 보다 작으면 키운다. 배경이 어두우면(반전 도면) 뒤집고, 스캔 잡음(이웃 픽셀 차이의 중앙값 > 2)이 있으면 5x5 중앙값 필터로 지우고, 회색 배경이면 배경을 흰색으로 펴서 대비를 맞춘다. 배경이 연회색 벽보다 어두우면(배경보다 밝은 봉우리가 따로 있으면) '배경과 다른 정도'를 잉크로 바꾼다. 유채색이 40% 넘거나 배경색이 30% 도 안 되는 이미지(사진 등), 가장 큰 벽 덩어리가 벽 픽셀의 10% 도 안 되는 이미지(글자만 있는 이미지)는 도면이 아니라고 안내한다
1. **벽 색 고르기**: 무채색 밝기 분포의 봉우리마다 그 밝기의 두꺼운 픽셀을 모아, 가장 넓게 이어진 덩어리를 만드는 색을 벽 색으로 고른다 (검게 칠한 CAD 도면, 연회색 디자인 도면 모두)
2. **벽 픽셀**: 벽 색 픽셀 중 5px 보다 얇은 것(치수선·글자·집기 선)을 지운다. 빗금(해치)이나 2~3줄로 그린 벽은 촘촘한 무늬를 메운 뒤, 길고 곧으며 긴 두 변이 곧은 선이고 다른 벽에 이어진 막대만 벽으로 더한다 (두께는 한 칸씩 재서 붙어 있는 곡선 가구는 빼고 곧은 부분만, 같은 줄에서 문 폭 이하 틈 너머로 이어지는 건물 안 벽도 포함). 아주 얇은 빗금벽은 바로 옆 가구와 뭉치기 전에 평행한 두 긴 선 사이의 빗금(잉크 15~75%)으로 따로 찾는다. 두 선 사이 속에 빗금·점무늬 잉크가 8% 도 없으면 속 빈 두 줄 선(책상·부스 칸막이 외곽, 계단 난간)이라 벽이 아니다. 건물 안에서 이런 칸막이가 3개 이상 붙은 긴 선은 책상 줄 테두리라 뺀다
3. **건물 영역**: 가장 큰 벽 덩어리에서 시작해 가까운 덩어리를 붙인다 (표제란·좌석표·로고·글자 조각 제외)
4. **창문 메우기**: 외벽의 칠해진 벽 사이가 얇은 선으로만 이어진 틈을 메운다 (건물 바깥과 맞닿고 긴 변이 벽에 붙지 않은 것만)
5. **외벽 닫기**: 건물 윤곽을 따라 고른 두께의 띠로 외벽을 깐다 (입구·문 틈까지). 외벽 안쪽으로 얕게 튀어나온 것(기둥 돌출·문틀)은 지우고, 깊이 들어가는 내부 벽은 뿌리만 남겨 잇는다
6. **얇은 벽 찾기** (연한 색으로 칠한 디자인 도면만, CAD 도면의 얇은 한 줄 선은 대부분 가구라서 쓰지 않음): 칠해진 벽을 뺀 벽 색 선 중 곧은 가로·세로 선(긴 변의 4% 이상)이 건물 안에 있고 한쪽 끝이 벽에 닿으면 칸막이로 되살린다. 짧은 선이 촘촘히 반복되는 무리(계단)는 빼고, 두 줄로 그린 벽은 한 벽으로 메운다
7. **좌석 도면처럼 단순화**: 건물 윤곽을 크게 단순화(직선·직각)해 고른 두께의 외벽 띠로 다시 그리고, 내부 벽은 가로·세로 막대로 나눠 모두 같은 두께(중앙값)로 그린다. 외벽은 원래 도면의 두께대로(내벽보다 얇지 않게) 그린다. 거의 한 줄인 벽은 한 줄로 맞추고, 벽 끝은 만나는 벽의 바깥 면에 맞춘다. 외벽에 붙은 꽉 찬 덩어리는 기둥 크기(외벽 두께의 6배 이하)만 기둥으로 남기고(벽에 붙은 탁자·카운터 제외), 막대로 나뉘지 않는 가는 덩어리(사선 벽)는 모양 그대로 둔다
8. **벽 잇기 (문은 그리지 않음)**: 좌석 도면처럼 문 자리를 비우지 않고 벽을 잇는다. 같은 줄(가로·세로)의 벽이 문 폭(1.3m) 이하 틈으로 떨어져 있으면 하나로 합치고, 다른 벽에 못 미친 벽 끝은 그 벽까지 늘리고, 이미 닿은 끝이라도 바로 너머(두께 2.5배 안)에 수직 벽이 있으면 거기까지 잇는다 (0.4m까지. 1.5m 이상 긴 벽은 늘릴 길에 원래 선이 절반 넘게 있을 때만 1.1m까지 — 빈 통로를 가로지르지 않게). 양 끝이 모두 떠 있는 짧은 막대(좌석 구분선 등)와 한쪽만 붙은 0.9m 미만 토막(문틀)은 지운다. 한쪽만 벽에 붙은 1.5m 미만 짧은 막대가 비슷한 길이로 3개 이상 일정한 간격(0.5~2.5m)으로 늘어서 있으면 좌석 칸막이라 지운다
9. **문**: 벽 중심선(또는 두 줄로 그린 벽의 면) 위 한 점(경첩)에서 1/4 원 문 열림 호가 그려져 있고, 문짝(곧은 선)이 있고, 문이 지나가는 안쪽이 비어 있으면 문 (문 폭 0.65~1.25m, 둥근 세면대·의자 등받이 제외). 벽 데이터는 이어진 채 두고, 그릴 때 문 폭만큼 벽을 비우고 흰 1/4 원을 그린다
10. **좌석**: 원본 px 에서 (연한 선까지 포함한) 선으로 둘러싸인 빈 칸을 본다 (칸 안의 치수 글자 같은 0.2m 미만 잉크는 무시)
   - 책상 칸: 짧은 변 0.45m 이상·긴 변 1.7m 이하의 꽉 찬 네모 + 한 변 바깥에 의자(잉크) → 좌석 1개 (정사각형, 의자 쪽으로 늘림)
   - 탁자: 1.7~5m × 0.5~1.6m 네모 + 긴 변 바깥에 의자 → 탁자(연한 회색)와 그 변 위 0.8m 마다 좌석
   - 칠한 좌석 상자(디자인 도면): 중간 회색으로 꽉 칠한 네모가 비슷한 크기로 3개 이상 반복되면 좌석
   - 정리: 겹치는 좌석은 하나만, 다른 좌석보다 훨씬 작은 칸(선반)·외톨이 칸(수납장)·벽과 겹치는 탁자 좌석 제외
   - 탁자 둘레 좌석은 다른 좌석과 같은 크기로 탁자 한쪽 끝부터 맞닿게
   - 번호: 벽으로 나뉜 방마다 A, B, C… (위→아래, 왼쪽→오른쪽). 방 안에서는 좌석이 옆으로 붙어 늘어선 방향을 줄로 보고 오른쪽 위부터 지그재그 (가로줄: 윗줄 오른쪽→왼쪽, 다음 줄 왼쪽→오른쪽 / 세로줄: 오른쪽 줄 위→아래, 다음 줄 아래→위)
11. **떨어진 덩어리 빼기**: 벽에 붙지 않은 기둥·화분·가구, 벽에 붙었어도 들쭉날쭉한 작은 덩어리는 그리지 않는다
12. **축척**: 입력한 가로 길이, 없으면 가로 15m 가정

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 (① 도면 이미지 ② 가로 길이 → 도면 생성 / 도면 보기·편집) |
| `trace.js` | 이미지 분석 (벽 색·벽 픽셀·창문 메우기·외벽 닫기·얇은 벽·좌석 도면식 단순화·벽 잇기·문·좌석·번호) |
| `app.js` | 화면 동작, 생성, 그리기(벽·문·탁자·좌석), 벽 그리기·지우기·구역 이름·되돌리기, 저장, PNG/JSON 내보내기 |
| `figma-plugin/` | JSON → Frame(투명) + 벽 모양·선 Vector(#D9D9D9) + 문(흰 1/4 원)·탁자·좌석(#AEAEAE, 흰 번호) |
| `tools/real-run.js` | 개발용: 사이트를 브라우저에서 그대로 돌려 결과 화면·plan.json 을 저장 |
| `tools/bench/` | 개발용 연습·채점: `gen.py` 가 정답 벽 마스크(문 자리도 벽)가 있는 연습 도면을 4가지 스타일로 만들고, `score.js` 가 벽 정확도·찾음을 잰다. `target.py` 는 사용자가 준 목표 그림(벽 #D9D9D9)과 결과를 겹쳐 점수를 낸다 |

Figma: `cd figma-plugin && npm i && npm run build` → Figma 데스크톱 *Plugins › Development › Import plugin from manifest* → 플러그인 창에 `smartfloor.json` 내용 붙여넣기 (Node 필요)

## 알려진 한계

- 얇은 벽은 곧은 가로·세로 선만 찾는다 (사선 얇은 벽, 벽에 닿지 않고 떨어져 있는 얇은 벽은 빠진다 → 직접 그리기)
- 좌석 옆 칸막이처럼 벽과 같은 색으로 칠한 두꺼운 선(속이 찬 것)이 반복되지 않고 하나둘만 있으면 벽으로 남는다 (🧽 벽 지우기로 지운다)
- 빗금 벽 도면을 스캔한 이미지는 빗금이 잡음과 함께 지워져 벽이 빠질 수 있다
- 내부 벽은 모두 같은 두께로 그린다 (실제 두께 차이는 표현하지 않는다)
- 좌석: 의자가 책상 칸 안에 그려진 부스형 책상(실제 CAD 도면 C 의 포커스존 등)은 아직 못 찾고, 복잡한 CAD 도면에서는 탁자·좌석을 잘못 잡는 경우가 있다 (🧽 지우기로 정리). 좌석을 손으로 추가하는 기능은 아직 없다
- 문: 문 열림 호가 그려진 문만 찾는다 (호 없이 틈만 있는 출입구는 벽으로 닫힌다)
- 책상 칸막이처럼 벽과 같은 두께로 그린 선은 벽으로 보고, 같은 줄이면 통로(1.3m 이하) 너머로 이어 그릴 수 있다
- 배포 후 예전 화면이 보이면 Ctrl+F5. 배포할 때 `index.html` 의 `?v=` 숫자를 올린다
- 저장본에 형식 버전(`v`)이 있어, 예전 형식으로 저장된 도면은 불러오지 않는다
